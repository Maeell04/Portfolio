# Automate

Projet réalisé en Python dans le cadre du cours Automates finis et expressions rationnelles, semestre 2 (L2).

## Contenu du projet

- `src/` : Contient le code source en Python
- `docs/` : Rapport PDF du projet

## Lancer le projet

1. Pré-requis : installez Python 3
2. Ouvrez un terminal dans le dossier `src/`
3. Exécutez le fichier principal : `python3 PP5_main.py`

## Technologies utilisées

- Langage : Python 3
- IDE : Visual Studio Code ou tout éditeur compatible Python
